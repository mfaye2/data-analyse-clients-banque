# Contexte du projet

Primero Bank fait face à un nombre important de départs de clients.

La direction marketing souhaite comprendre les caractéristiques communes des clients ayant quitté la banque afin de mettre en place un plan d’action pour limiter de nouveaux départs.

## Objectifs

Le projet vise à :

- identifier le profil des clients perdus ;
- analyser les facteurs associés à l’attrition ;
- proposer au moins cinq pistes d’explication ;
- repérer les clients actuels présentant des signaux de risque ;
- présenter les résultats dans un dashboard Power BI ;
- formuler des recommandations métier.

## Livrables

- notebooks Python d’exploration, nettoyage et analyse ;
- fichiers de données nettoyées ;
- score métier de risque ;
- dashboard Power BI ;
- rapport d’analyse ;
- recommandations métier.
