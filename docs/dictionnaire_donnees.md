# Dictionnaire des données

| Colonne | Description |
|---|---|
| N° du client | Identifiant unique du client |
| Statut du client | Indique si le client est actuel ou perdu |
| Âge du client | Âge du client en années |
| Genre du client | Genre déclaré du client |
| Nb de personnes à charge | Nombre de personnes à charge |
| Niveau de diplôme | Niveau de formation du client |
| Statut marital | Situation matrimoniale |
| Catégorie du revenu annuel | Tranche de revenu annuel |
| Type de carte | Type de carte bancaire détenue |
| Durée d'engagement en mois | Ancienneté du client auprès de la banque |
| Nb de mois inactif | Nombre de mois sans activité sur les 12 derniers mois |
| Nb d'interactions | Nombre de contacts avec la banque sur les 12 derniers mois |
| Montant crédit renouvelé | Montant du crédit renouvelé |
| Nb de transactions | Nombre de transactions réalisées |
| Utilisation moyenne de la carte | Niveau moyen d’utilisation de la carte |
| attrition | Variable binaire : 1 si le client est perdu, 0 sinon |
| score_risque | Nombre de signaux de risque détectés |
| niveau_risque | Niveau Faible, Modéré ou Élevé |
